# Taller-02

This repository contains a full-stack authentication application with a FastAPI backend and a React frontend.

## Projects

| Folder       | Description                                                  |
|--------------|--------------------------------------------------------------|
| `backend/`   | FastAPI JWT authentication API (Python / Poetry)             |
| `frontend/`  | React SPA with login and welcome pages (Vite / React Router) |

Refer to each folder's `README.md` for detailed setup instructions:
- [Backend README](backend/README.md)
- [Frontend README](frontend/README.md)
